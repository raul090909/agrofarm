# Сельхозферма — сервер и панель агронома

Проект для развёртывания на Render.com: один веб-сервис (Spring Boot + собранная панель React) и база PostgreSQL.
При первом запуске сервер сам создаёт таблицы и заполняет демонстрационные данные.

- Панель агронома: `https://<адрес>.onrender.com` — логин `agronom`, пароль `agro123`
- Мобильное приложение: шестерёнка на экране входа → `https://<адрес>.onrender.com`, вход `ivan@test.ru` / `pass123`
